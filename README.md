## 📋 Что это?

**AI-Юрист** - это готовое решение для создания бота, который анализирует юридические документы (договоры, NDA, трудовые соглашения) и выявляет риски с использованием:

- 🔥 **Firecrawl** - парсинг юридических источников (законы РК, судебная практика)
- 🗄️ **Supabase** - векторная база знаний для семантического поиска
- 🤖 **OpenAI GPT-4** - глубокий анализ с максимальным контекстом (128K токенов)
- ⚙️ **n8n** - оркестрация всех процессов

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Требования:
- n8n (self-hosted или cloud)
- Supabase аккаунт (free tier)
- Firecrawl API ключ (Hobby план, $20/мес)
- OpenAI API ключ
```

### 2. Настройка базы данных

```bash
# 1. Создайте проект в Supabase
# 2. SQL Editor → выполните supabase_schema.sql
# 3. Скопируйте connection string
```

### 3. Импорт workflows

```bash
# В n8n импортируйте по очереди:
1. workflow_1_legal_knowledge_parser.json  # Парсинг законов
2. MODIFIED_MAIN_WORKFLOW.json             # Основной обработчик
3. workflow_3_subscription_management.json  # Команды бота
```

### 4. Первый запуск

```bash
# Запустите парсинг юридической базы (один раз):
1. Откройте workflow "Legal Knowledge Parser"
2. Execute Workflow
3. Дождитесь завершения (10-30 минут)
4. Проверьте: SELECT COUNT(*) FROM legal_knowledge;
```

### 5. Тестирование

```bash
# Отправьте боту тестовый договор из test_data_and_scripts.md
# Ожидаемый результат: детальный анализ с рисками и рекомендациями
```

## 📊 Техническая спецификация

### Компоненты системы

| Компонент | Технология | Назначение |
|-----------|------------|------------|
| Message Handler | n8n | Обработка входящих сообщений |
| OCR | Google Apps Script | Извлечение текста из PDF |
| Document Classifier | GPT-4o | Определение типа документа |
| Vector Search | Supabase pgvector | Поиск релевантного контекста |
| Legal Analyzer | GPT-4o (4K tokens) | Глубокий анализ рисков |
| Knowledge Base | Firecrawl + Supabase | База законов и практики |
| Subscription Manager | PostgreSQL | Лимиты и платежи |

### Потоки данных

```
Документ (PDF)
    ↓
OCR → Текст
    ↓
Векторизация → [1536 float] embedding
    ↓
Semantic Search → Top-10 релевантных статей закона
    ↓
GPT-4 Analysis → Структурированный JSON с рисками
    ↓
Форматирование → Красивое сообщение пользователю
    ↓
Сохранение → База данных (история + статистика)
```

## 🔑 Ключевые файлы

### Workflows

- **workflow_1_legal_knowledge_parser.json** (Еженедельно)
  - Парсит zakon.kz, sud.gov.kz через Firecrawl
  - Чанкирует по 1000 символов
  - Векторизует через OpenAI
  - Сохраняет в Supabase
  - ~1000 Firecrawl кредитов на запуск

- **MODIFIED_MAIN_WORKFLOW.json** (Основной)
  - Обработка входящих файлов
  - Детекция юридических документов
  - Проверка лимитов
  - Векторный поиск контекста
  - AI анализ (GPT-4o)
  - Отправка результата

- **workflow_3_subscription_management.json** (Вспомогательный)
  - Команды: /start, /help, /balance, /pay
  - Обработка платежей
  - Управление подписками

### База данных

- **legal_knowledge** - 1000+ векторов (статьи законов)
- **analyzed_documents** - История анализов
- **user_limits** - Лимиты и подписки
- **analysis_templates** - Промпты для разных типов
- **payments** - Транзакции

## 🐛 Известные проблемы и решения

### Проблема: Firecrawl timeout

**Решение:** Используйте webhooks вместо синхронного ожидания

```javascript
// Вместо Wait → Check Status
// Используйте webhook callback
{
  webhook: {
    url: "https://your-n8n.com/webhook/firecrawl-done",
    events: ["completed", "failed"]
  }
}
```

### Проблема: Медленный векторный поиск

**Решение:** Оптимизируйте индексы

```sql
-- Увеличьте количество lists для ivfflat
DROP INDEX idx_legal_knowledge_embedding;
CREATE INDEX idx_legal_knowledge_embedding 
ON legal_knowledge 
USING ivfflat (embedding vector_cosine_ops)
WITH (lists = 200);
```

### Проблема: AI не возвращает JSON

**Решение:** Используйте function calling

```javascript
// Вместо обычного промпта используйте tools:
{
  model: "gpt-4o",
  messages: [...],
  tools: [{
    type: "function",
    function: {
      name: "analyze_contract",
      description: "Analyze legal contract",
      parameters: {
        type: "object",
        properties: {
          overall_risk_score: { type: "number" },
          risk_points: { type: "array", items: {...} }
        }
      }
    }
  }],
  tool_choice: { type: "function", function: { name: "analyze_contract" } }
}
```
