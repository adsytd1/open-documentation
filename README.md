
```
<think>

□ Статьи 401-405 (не 406-410)?
```

## 💡 ПОЧЕМУ ЭТО РАБОТАЕТ

### 1. Chain-of-Thought заставляет AI ДУМАТЬ

Модель `sonar-reasoning-pro` поддерживает `<think>` теги.

**AI обязан:**
```
<think>
1. Определяю тип помещения из документа
2. Смотрю в проверенную базу законов
3. Выбираю правильную статью (556 или 575)
4. Проверяю через поиск по adilet.zan.kz
5. Сверяю номер с содержанием
6. Только потом упоминаю
</think>
```

**AI не может пропустить эти шаги** — модель обучена следовать reasoning инструкциям.

---

### 2. AI видит свои РЕАЛЬНЫЕ ошибки

В промпте есть раздел с реальными ошибками из прошлых анализов:

```
❌ ОШИБКА #1:
"Статья 575 для нежилого помещения (офиса)"

ПОЧЕМУ ОШИБКА:
Статья 575 - Глава 30 "Аренда ЖИЛОГО помещения"
Для нежилых правильная статья 556

✅ ПРАВИЛЬНО:
"Статья 556 ГК РК (Особенная часть, Глава 29)..."
```

**AI знает ЧТО именно он делал неправильно** и как исправить.
