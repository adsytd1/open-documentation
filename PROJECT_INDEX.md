### 📋 Workflows для n8n

| Файл | Описание | Когда использовать |
|------|----------|-------------------|
| **workflow_1_legal_knowledge_parser.json** | Парсинг юридических источников через Firecrawl | Импортировать первым, запустить раз в неделю |
| **workflow_2_document_analysis.json** | Логика анализа документов | Для понимания структуры (можно не импортировать) |
| **workflow_3_subscription_management.json** | Команды бота (/start, /pay, etc) | Импортировать для работы команд |
| **MODIFIED_MAIN_WORKFLOW.json** | Расширенная версия вашего flow | Использовать как референс для интеграции |
| **integration_nodes.json** | Отдельные узлы для добавления | Копировать узлы в ваш workflow |

### 🗄️ База данных

| Файл | Содержание | Действие |
|------|------------|----------|
| **supabase_schema.sql** | Полная SQL схема (5 таблиц + функции) | Выполнить в Supabase SQL Editor |

Таблицы:
- `legal_knowledge` - Векторная база законов (главная!)
- `analyzed_documents` - История анализов пользователей
- `user_limits` - Лимиты и подписки
- `analysis_templates` - Промпты для разных типов документов
- `payments` - Транзакции

Функции:
- `check_user_limit()` - Проверка прав на анализ
- `increment_analysis_usage()` - Уменьшение лимита
- `match_legal_documents()` - Векторный поиск
- `add_analyses_from_payment()` - Активация пакета
- `reset_monthly_limits()` - Сброс счетчиков

### 🎓 Документация и руководства

| Файл | Содержание | Когда читать |
|------|------------|--------------|
| **STEP_BY_STEP_INTEGRATION.md** | Пошаговая интеграция с проверками | После базовой настройки |

| **ARCHITECTURE_AND_CHECKLIST.md** | Диаграммы и чеклисты | Перед запуском |

├─ user_limits (подписки)
├─ payments (транзакции)
└─ analyzed_documents (последние 7 дней)

```

### Recovery procedures

```
Сценарий 1: Упала база данных
└─> Restore из последнего backup
    Время: ~10 минут
    Потеря данных: <24 часа

Сценарий 2: Сломался workflow
└─> Откат на предыдущую версию из Git
    Время: ~5 минут
    Потеря: только новые запросы во время простоя

Сценарий 3: Кончились Firecrawl кредиты
└─> Временно отключить обновление базы
    База работает на старых данных
    Срочно купить кредиты
