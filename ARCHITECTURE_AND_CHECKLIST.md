## 📊 Capacity Planning

### Расчет нагрузки

```
Сценарий: 1000 активных пользователей в месяц
Конверсия: 10% в платящих

Объем операций:
├─ Новые пользователи: 1000/месяц
├─ FREE анализы: 1000 × 1 = 1000
├─ Платные анализы: 100 × 10 (средний пакет) = 1000
└─ Итого анализов: 2000/месяц = 67/день

Нагрузка на компоненты:

OpenAI:
├─ Embeddings: 2000 запросов × $0.00002 = $0.04
├─ Type detection: 2000 × $0.00015 = $0.30
├─ Analysis: 2000 × $0.10 = $200
└─ Итого: ~$200/месяц

Firecrawl:
├─ Еженедельный парсинг: 4 × 200 = 800 кредитов
├─ Итого: ~$3.20/месяц (в рамках Hobby плана)

Supabase:
├─ Database: ~200MB (FREE tier достаточно)
├─ API calls: ~10K/месяц (FREE tier)
└─ Cost: $0

N8N:
├─ Self-hosted
└─ Cost: $0 (или $5-10 VPS)

ИТОГО расходы: ~$210/месяц
ДОХОД (при 100 покупок × 4000₸): ~$840
ПРИБЫЛЬ: ~$630/месяц (при 1K пользователей)
```

### Scaling points

```
Когда нужен upgrade:

Supabase FREE → PRO ($25/мес):
• При >500MB database
• При >10K пользователей
• При >1M вектров

Firecrawl Hobby → Standard ($150/мес):
• При >5K анализов/месяц
• При >500K кредитов/месяц

OpenAI Tier 1 → Tier 2:
• Автоматически при >$100/месяц
• Более высокие rate limits
```
